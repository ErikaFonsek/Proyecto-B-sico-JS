# Registro de Usuarios - JavaScript

Este proyecto es una aplicación web sencilla desarrollada con HTML, Bootstrap y JavaScript puro, pensada como práctica para aprender los conceptos básicos de JavaScript y la manipulación del DOM.

# Funcionalidades

- Formulario de registro de usuarios
- Validación de campos (nombre, apellido y edad)
- Mensajes visuales usando Bootstrap Alerts
- Limpieza automática del formulario
- Interfaz responsiva con Bootstrap

## Tecnologías utilizadas

- HTML5
- CSS (Bootstrap 5)
- JavaScript (Vanilla JS)

## Cómo ejecutar el proyecto

1. Clona o descarga este repositorio
2. Abre el archivo `index.html` en tu navegador
3. Completa el formulario y presiona **Guardar Datos**

## Objetivo del proyecto

Este proyecto fue creado con fines educativos para reforzar:

- Uso de formularios HTML
- Validaciones con JavaScript
- Manipulación del DOM
- Buenas prácticas en la organización de archivos
